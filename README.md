# push_swap

***

# Description
The push_swap program sorts a stack of integers using the fewest possible operations, drawn from a limited set (pa, ra, sa — push to a, rotate a, swap a, and their counterparts). Given stack a with n unsorted integers, the goal is to reach a disorder metric of 0 (a fully sorted stack), using a second stack, b, as working space along the way.

The project implements three tiers of sorting strategy — easy, medium, and hard — each suited to a different input size. The easy tier works well for small inputs; the medium tier divides the numbers into roughly √n groups; the hard tier is a more sophisticated algorithm suited to large inputs. Rather than picking one approach, the program uses the stack's disorder metric to automatically select which tier's algorithm to run.

# Instructions

### Building the Program
To build `push_swap`, type the following command in your terminal:
```bash
make
```

### Maintenance Rules
* Remove temporary binary object files (`.o` files):
```bash
  make clean
```
* Remove object files AND the final compiled `push_swap`:
```bash
  make fclean
```
* Force a complete clean rebuild of the program from scratch:
```bash
  make re
```

### Running the Program
To run `push_swap`, type the following command in your terminal:
```bash
./push_swap 3 1 2
```
As a result of running the program, a list of operations will be printed out, each on a separate line. If the stack is already sorted (has a disorder metric of 0) then there will be no output at all.

## Algorithm

The disorder metric is used to determine which algorithm is suitable for sorting a stack. A disorder metric value is a number between 0 and 1 that indicates the degree of order in a stack (less than 0.2 being almost sorted, between 0.2 and 0.5 being partially sorted, and more than or equal to 0.5 being very disordered). It is calculated by considering all of the pairs of numbers in a stack. Every time a larger number appears before a smaller one, this is considered to be a "mistake." The number of mistakes divided by the total number of pairs gives us the disorder metric value. The disorder metric value is obtained before any operations, because it decides which tier of sorting (easy, medium, complex, and an adaptive algorithm) will be used to sort the stack.

**Tier 1, Easy — Min/Max extraction sort (O(n²)):** This algorithm is meant to find the minimum and maximum values of a stack simultaneously and place them at the beginning and end of the stack respectively. This is done recursively until the stack is sorted.

**Tier 2, Medium — Chunk-based sort (O(n√n)):** This algorithm sorts through the stack by splitting it into √n amount of chunks (this happens in stack b). Each chunk is then organised one at a time, pushing the elements back to stack a in order.

**Tier 3, Complex — Radix sort (O(n log n)):** This algorithm sorts the elements based on bits of each number (which is why it sorts fast), separating 0-bit from 1-bit numbers, starting from the least significant bit. This happens until the stack is ordered.

The disorder metric is calculated first. This determines which sorting algorithm runs (the adaptive algorithm is still a work in progress). The benefit of having more than one algorithm to sort stacks is that the appropriate algorithm will run, avoiding the use of a simple algorithm on a stack with a disorder metric greater than or equal to 0.5 (very disordered).
